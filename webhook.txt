=== WEBHOOK REQUEST FLOW ===

1. User clicks "Secure This Bounty" button on bounty detail page
   → Redirects to Stripe Checkout (payment page)
2. User completes payment in Stripe
3. Stripe sends webhook POST to /bounties/stripe-webhook
4. Webhook processes event:
   - Validates signature (or skips in dev mode)
   - Finds bounty_id in metadata
   - Updates bounty.payment_status = 'secured'
   - Updates bounty.stripe_payment_intent
   - Returns HTTP 200
5. User redirected back to bounty detail page
   → Page shows "Secured" badge

=== STRIPE DASHBOARD CONFIGURATION ===

To receive real payments, must configure in Stripe Dashboard:
1. Go to: Developers → Webhooks
2. Add endpoint: https://paid2match.work/bounties/stripe-webhook
3. Select events: checkout.session.completed
4. Get signing secret and add to AdminSettings: STRIPE_WEBHOOK_SECRET
